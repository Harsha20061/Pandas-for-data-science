# Pandas Learning Journey

A structured repository documenting my hands-on learning journey with **Pandas**, the Python library for data manipulation and analysis.

This repository contains notes, practice exercises, coding challenges, and projects completed while learning Pandas from the fundamentals.

---

## Overview

Pandas is one of the most widely used Python libraries for working with structured data. It provides powerful data structures such as **Series** and **DataFrame** for data cleaning, transformation, analysis, and preparation.

This repository serves as a record of my daily progress while learning Pandas through practical coding.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/pandas-learning.git
```

Navigate into the repository:

```bash
cd pandas-learning
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run a Python file:

```bash
python Notes/day1.py
```
